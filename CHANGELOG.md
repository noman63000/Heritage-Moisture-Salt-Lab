# Changelog

## v1.5.0 - publication bundle (2026-10-04)

Publication-facing source bundle for the Mohenjo-daro R00-R20 study. It consolidates the verified reduced 1-D scientific core, final execution/phase extensions, AnalysisBridge v1.2.0, HAMSTAD Benchmark 2 evidence, climate disaggregation validation, boundary sensitivity evidence, frozen configuration and source-data manifests.

Component lineage retained in the repository:
- Heritage Moisture & Salt Lab scientific core: v1.2.0, with v1.2.1 preparation UI update.
- Parallel/resumable execution layer: v1.1 lineage.
- Pore-liquid / equilibrium phase execution extension: v1.4 lineage.
- AnalysisBridge: v1.2.0.

This bundle does not imply site-specific predictive validation or mechanical salt-damage modelling.
