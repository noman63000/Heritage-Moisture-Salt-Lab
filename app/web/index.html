What this application calculates

Climate summaries, and a reduced one-dimensional vertical heat, moisture and Na2SO4-equivalent transport model. The wall is averaged across its thickness. A supplied solubility table enables an optional single-salt equilibrium partition.

This is not a full mixed-ion thermodynamic model, a two-dimensional wall/soil model or a calibrated deterioration predictor. Climate crossings are not crystallisation events. The included workbook is kept as an audit source, not rewritten.

Review before transport

1.1 wet-end correction: when net water inflow would exceed an exposed cell's supported storage, it leaves as liquid seepage with dissolved salt. This is a reduced free-draining-face assumption, not a measured site drainage law. The supported table endpoint and effective saturation are reported separately; no curve is extended. First-time workflow

  1. Open the synthetic demonstration project to test the application without pretending that the example is real.
  2. Select Mohenjo-daro, validate the files and inspect the included climate-screening results.
  3. Download/import the original 18_15 material file. Its absence cannot be fixed by inventing a curve from porosity.
  4. Review boundary and geometry assumptions in Settings. Import a sourced solubility table only when an equilibrium partition is needed.
  5. Run a trial, then numerical QA and spin-up. Freeze the reduced inputs before full runs.
  6. Keep reports, checkpoints and source hashes together. Validate against independent measurements before making site-specific predictions.
