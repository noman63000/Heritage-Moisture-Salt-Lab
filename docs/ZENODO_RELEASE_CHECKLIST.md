# Zenodo release checklist

1. Confirm repository content and authorship metadata.
2. Add all software authors and ORCIDs to `CITATION.cff` before release.
3. Confirm the repository is public.
4. Connect this GitHub repository in Zenodo's GitHub integration.
5. Create GitHub tag/release `v1.5.0` only after the repository audit is complete.
6. Confirm Zenodo archives the release and assign/reserve the software DOI.
7. Add that DOI to `README.md`, `CITATION.cff`, and the manuscript availability statement.
8. Create a separate Zenodo **Dataset** record for the R00-R20 processed data and large outputs.
9. Cross-link software DOI, dataset DOI and article DOI when available.
